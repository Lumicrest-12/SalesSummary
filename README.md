# SalesSummary

โปรแกรมสรุปยอดขายจากไฟล์ Excel/CSV อัตโนมัติ เขียนด้วย Python + Pandas
ได้ผลเป็นไฟล์ Excel พร้อมกราฟ ภายในไม่กี่วินาที

## สิ่งที่ได้ในไฟล์ผลลัพธ์

ไฟล์ผลลัพธ์มี 3 ชีต:

| ชีต | เนื้อหา |
|---|---|
| **สรุปภาพรวม** | ยอดขายรวม, จำนวนชิ้น, ยอดเฉลี่ยต่อวัน, วันที่ขายดีที่สุด, สินค้าขายดีอันดับ 1 |
| **สินค้าขายดี** | จัดอันดับสินค้าตามยอดขาย + สัดส่วน % + กราฟแท่ง |
| **ยอดขายรายวัน** | ยอดขายแต่ละวัน + กราฟเส้น |

## ฟีเจอร์

- เลือกไฟล์ผ่านหน้าต่าง หรือระบุผ่านคำสั่งก็ได้
- รองรับ `.xlsx`, `.xls` และ `.csv` (รวมถึง CSV ภาษาไทยแบบเก่า)
- รู้จักหัวคอลัมน์ทั้งภาษาไทยและอังกฤษ
- รองรับปี พ.ศ. และตัวเลขที่มีคอมมา (เช่น `1,200`)
- ข้ามแถวที่ข้อมูลไม่ครบและแจ้งจำนวนที่ข้าม แทนที่จะหยุดทำงาน
- ทำงานในเครื่องเท่านั้น ไม่ส่งข้อมูลออกอินเทอร์เน็ต

## วิธีใช้

### เวอร์ชัน .exe (ไม่ต้องติดตั้งอะไร)

1. ดับเบิลคลิก `SalesSummary.exe`
2. เลือกไฟล์ยอดขาย (`.xlsx`, `.xls` หรือ `.csv`)
3. รอสักครู่ จะมีข้อความ "สรุปเสร็จแล้ว"
4. เปิดไฟล์ `<ชื่อไฟล์เดิม>_สรุป.xlsx` ที่อยู่โฟลเดอร์เดียวกับไฟล์ยอดขาย

> ทางลัด: ลากไฟล์ยอดขายมาวางทับ `SalesSummary.exe` ได้เลย

### เวอร์ชัน Python

ติดตั้งครั้งแรก:

```
pip install -r requirements.txt
```

รันโปรแกรม:

```
python sales_summary.py                        # เปิดหน้าต่างเลือกไฟล์
python sales_summary.py ยอดขาย.xlsx             # ระบุไฟล์เอง
python sales_summary.py ยอดขาย.csv -o ผล.xlsx   # ตั้งชื่อไฟล์ผลลัพธ์
python sales_summary.py ยอดขาย.csv --top 5      # กราฟสินค้าขายดี 5 อันดับ
```

## รูปแบบไฟล์ยอดขาย

แถวแรกต้องเป็นหัวคอลัมน์ ใช้ชื่อไทยหรืออังกฤษก็ได้:

| ข้อมูล | ชื่อหัวคอลัมน์ที่รู้จัก | จำเป็น |
|---|---|---|
| วันที่ | `วันที่`, `วัน`, `วันที่ขาย`, `Date` | ใช่ |
| สินค้า | `สินค้า`, `ชื่อสินค้า`, `รายการ`, `Product`, `Item` | ใช่ |
| จำนวน | `จำนวน`, `Qty`, `Quantity` | ใช้คู่กับราคา |
| ราคา | `ราคา`, `ราคาต่อหน่วย`, `Price` | ใช้คู่กับจำนวน |
| ยอดรวม | `ยอดรวม`, `ยอดขาย`, `จำนวนเงิน`, `Total`, `Amount` | ใช้แทนจำนวน + ราคาได้ |

ต้องมี **วันที่** และ **สินค้า** และต้องมี **ยอดรวม** หรือมีทั้ง **จำนวน + ราคา** (โปรแกรมคำนวณยอดรวมให้เอง)

ตัวอย่าง:

| วันที่ | ชื่อสินค้า | จำนวน | ราคา |
|---|---|---|---|
| 01/09/2025 | ข้าวผัดกะเพรา | 2 | 60 |
| 01/09/2025 | ชาไทยเย็น | 1 | 35 |

มีไฟล์ตัวอย่างให้ลองในโฟลเดอร์ [`samples/`](samples/)

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ไม่พบคอลัมน์ที่จำเป็น | หัวคอลัมน์ไม่ตรงกับตารางด้านบน แก้ชื่อในไฟล์แล้วลองใหม่ |
| บันทึกไฟล์ไม่ได้ | ไฟล์ผลลัพธ์เปิดค้างใน Excel ปิดก่อนแล้วรันใหม่ |
| ข้ามแถวที่ข้อมูลไม่ครบ X แถว | เป็นปกติ โปรแกรมข้ามแถวที่วันที่/สินค้า/ยอดเงินว่างหรือผิดรูปแบบ ตรวจสอบแถวเหล่านั้นในไฟล์ต้นฉบับ |
| หน้าต่างเลือกไฟล์ไม่ขึ้น | ดูที่แถบงาน อาจซ่อนอยู่หลังหน้าต่างอื่น หรือลากไฟล์มาวางทับโปรแกรม หรือระบุชื่อไฟล์ท้ายคำสั่ง |
| `No module named 'tkinter'` | ติดตั้ง Python ใหม่แล้วติ๊ก "tcl/tk and IDLE" (Windows) หรือ `sudo apt install python3-tk` (Ubuntu) |
